# Política de segurança

## Versões com suporte

A versão atual na branch `main` recebe correções de segurança.

## Reportar uma vulnerabilidade

Não abra issue pública para falha de segurança.

Envie um e-mail para fredrumond@gmail.com com:

- descrição do problema e o impacto
- passos para reproduzir, ou um proof of concept mínimo
- versões afetadas, se você souber

Você recebe uma confirmação de recebimento. Correções saem por pull request ou advisory depois que o relato for confirmado. Não publique os detalhes antes da correção estar disponível.
